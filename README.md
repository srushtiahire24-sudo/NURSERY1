# Paradise Nursery

Paradise Nursery is a React plant-shopping application. Browse houseplants by category, add plants to a shopping cart, change quantities, and view the total.

## Technologies
- React
- Redux Toolkit
- React Redux
- Vite
- CSS

## Run locally
1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL printed in the terminal.

## Features
- Landing page with company information and Get Started button
- Categorized plant listings
- Add-to-cart functionality
- Quantity controls and item removal
- Cart subtotal and total calculation
